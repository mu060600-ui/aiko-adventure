# 아이코와 함께하는 데이터센터 탐험 (AIKO's Data Center Adventure)

AI KOREA 마스코트 아이코를 조종해 여섯 규모의 데이터센터를 돌아다니며 서버, 냉각, 전력 설비를 배우는 3D 웹 게임입니다.

**바로 하기: https://mu060600-ui.github.io/aiko-adventure/**

- 설치 없이 PC와 모바일 브라우저에서 실행됩니다. 한국어와 영어를 지원합니다.
- 조작: W 전진, S 후진, A·D 방향 전환, Shift 달리기, E 살펴보기, F 내부 상세보기, M 지도, ESC 메뉴
- 모든 설비 모델과 수치는 교육용 개념 표현입니다. 제조사 CAD나 실제 설계가 아니며, 시뮬레이터 수치는 실제 설계와 견적을 대체하지 않습니다.
- Supermicro 제품 사양은 Supermicro 공식 홈페이지에서 2026-11-25에 확인한 내용을 인용했습니다. 제품명과 상표는 각 회사의 자산입니다.
